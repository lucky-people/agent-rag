# 租房知识普及指南（租客权益与避坑实务）

## 一、租房前必须确认的事项

1. 确认房东身份与房屋权属：要求房东出示身份证原件，并核对与房屋产权证（不动产登记证明）是否一致；若为二房东转租，必须取得原房东书面同意，否则合同可能无效或随时被解除。（法律依据：《民法典》第七百一十六条——承租人经出租人同意，可以将租赁物转租给第三人）
2. 确认租赁合同关键条款：租期起止、月租金及支付方式、押金数额与退还条件、水电燃气物业费承担、维修责任划分、提前退租与违约条款、是否允许转租。（法律依据：《民法典》第七百零七条——租赁期限六个月以上的，应当采用书面形式）
3. 确认房屋真实状况：实地看房，检查墙面、地板、门窗、水电燃气是否正常，家电家具是否完好；入住前对全屋拍照录像留证，写明家具家电清单并双方签字。（法律依据：《民法典》第七百零八条——出租人应当按照约定将租赁物交付承租人）
4. 确认费用明细：明确物业费、取暖费、水电气网费由谁承担、单价多少，避免退租时被要求补缴不明费用。（法律依据：《民法典》第七百一十二条——出租人应当履行租赁物的维修义务）
5. 确认退租条件：提前多少天通知、押金在什么情况下全额退还、搬离后交接流程，最好写入合同。（法律依据：《民法典》第七百三十条——不定期租赁，当事人可以随时解除合同，但应当在合理期限之前通知对方）

## 二、租客的核心合法权益（法律依据）

1. 买卖不破租赁：租赁物在承租人按照租赁合同占有期限内发生所有权变动的，不影响租赁合同的效力。（《民法典》第七百二十五条）——房东在租期内卖房，新房东必须继续履行原合同，无权要求租客提前搬走。
2. 承租人优先购买权：出租人出卖租赁房屋的，应当在出卖之前的合理期限内通知承租人，承租人享有以同等条件优先购买的权利。（《民法典》第七百二十六条）
3. 承租人优先承租权：租赁期限届满，房屋承租人享有以同等条件优先承租的权利。（《民法典》第七百三十四条）
4. 正常损耗不担责：承租人按照约定的方法或者根据租赁物的性质使用租赁物，致使租赁物受到损耗的，不承担赔偿责任。正常居住导致的老化、墙面轻微发黄、地板轻微磨损属于自然损耗，租客无需赔偿，房东不得以此扣押金。（《民法典》第七百一十条）
5. 押金应当返还：租期届满，承租人返还租赁物符合约定状态（正常使用后的损耗除外），出租人应当返还押金。（《民法典》第七百三十三条）
6. 未定期限合同可随时解除：当事人对租赁期限没有约定或约定不明确，视为不定期租赁，当事人可以随时解除合同，但应当在合理期限之前通知对方。（《民法典》第七百三十条）
7. 房屋危及安全可随时解除：租赁物危及承租人的安全或健康的，即使承租人订立合同时明知该租赁物质量不合格，承租人仍然可以随时解除合同。（《民法典》第七百三十一条）
8. 维修义务在出租人：出租人应当履行租赁物的维修义务，但当事人另有约定的除外。（《民法典》第七百一十二条）出租人未履行维修义务的，承租人可以自行维修，维修费用由出租人负担。

## 三、押金注意事项

1. 押金本质是担保金，所有权属于租客，不是房东可以私自没收的钱。押金数额一般不超过一个月租金（部分城市规定不超过两个月）。（法律依据：《民法典》第七百三十三条——租期届满，承租人返还租赁物符合约定状态的，出租人应当返还押金）
2. 退押金条件：正常退租、无欠费、无人为损坏，房东应当全额退还押金。（法律依据：《民法典》第七百三十三条）
3. 房东可以合理扣减押金的两种情形：承租人拖欠房租、水电物业等费用；承租人人为损坏家具家电、墙体，需抵扣维修费用。房东扣钱必须出示证据。（法律依据：《民法典》第七百一十条——正常损耗不担责；第七百三十三条——押金应当返还）
4. 交付押金务必索要收据或保留转账记录，并在合同中写明"押金xx元，退租时无欠费无损坏全额退还"。
5. 房东无故拒不退还押金属于民事违约，可先书面催告，再向12345投诉调解，最后通过人民法院在线服务起诉（标的1万以内属小额诉讼，诉讼费低至25-50元，一审终审）。（法律依据：《民法典》第七百三十三条）

## 四、常见纠纷与应对

1. 房东中途卖房要求搬走：依据买卖不破租赁（《民法典》第七百二十五条），新房东必须继续履行合同，租客有权拒绝提前搬走；房东或新房东强令搬走属违约，可要求其承担违约责任。
2. 租期内房东单方涨租：合同期内租金按合同约定执行，房东无权单方涨租；合同到期后续租，双方可重新协商租金。
3. 房东不退押金：先书面催告并保存记录，再打12345投诉或街道司法所调解，最后线上起诉，标的1万以内小额诉讼流程简单、无需律师。（法律依据：《民法典》第七百三十三条）
4. 房屋漏水、家电损坏无人修：出租人负有维修义务（《民法典》第七百一十二条），租客催告后仍不修的可自行维修并保留票据，费用由房东承担，必要时可抵扣租金（需谨慎并留证据）。
5. 提前退租违约：按合同约定承担违约责任，通常为一个月租金或押金；若合同未约定或违约金过高，可请求法院适当降低。

## 五、签约防坑要点

1. 警惕霸王条款：如"无论何种原因押金不退""租客承担一切维修费""房东可随时终止合同"等，这类免除出租人责任、加重承租人责任、排除承租人主要权利的格式条款无效。（法律依据：《民法典》第四百九十七条——提供格式条款一方不合理地免除或者减轻其责任、加重对方责任、限制对方主要权利的，该格式条款无效）
2. 口头承诺必须写进合同：房东口头答应的"可养宠物""可转租""免费维修"等，务必白纸黑字写进合同，否则难以举证。
3. 留存全部证据：合同、押金收据、转账记录、看房照片视频、聊天记录、缴费凭证，退租纠纷时这些都是核心证据。
4. 写明交付与退租状态：合同附房屋交接清单，注明家具家电现状、水电表读数，退租时按清单核验，避免扯皮。（法律依据：《民法典》第七百三十三条——符合约定状态返还房屋即可退还押金）
5. 通过正规渠道租房：优先选择正规中介、正规平台或与房东直签，警惕"先交定金后看房""低价租房先交钱"等骗局。
