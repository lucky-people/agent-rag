▼ 效果
设计优点： ① 进程内会话 + TTL 清理，轻量且无外部依赖，适合单机演示；② 锁内写保证并发安全；③ 用户画像存 MySQL 可跨会话复用； ④ 历史窗口裁剪（最近 N 轮）控制 LLM 上下文成本；⑤ 短 / 长记忆分离，短期管上下文、长期管个性化。
